# Работа в репозитории

- Стек: React, Vite, TypeScript. Сайт публикуется на GitHub Pages.
- Перед изменением прочитай ближайшие вложенные `AGENTS.md`: они уточняют правила своей области.
- Держи изменения в рамках задачи. Сохраняй чужие правки и существующие публичные адреса.
- Перед правкой найди места, которые используют изменяемый код. Ищи самое простое решение, которое полностью закрывает задачу. Начни с кода проекта, затем проверь возможности платформы и установленные зависимости.
- Если задача требует нового движка, зависимости или переделки нескольких частей проекта, до реализации объясни зачем. Если есть более простой вариант, назови его и укажи, где его перестанет хватать.
- Зависимости добавляй для конкретной задачи; используй npm и обновляй lock-файл вместе с package.json.
- Не коммить секреты, node_modules, dist и локальные настройки.
- Проверяй изменения командами из README и воспроизводи сценарий, который может сломаться из-за правки. Для новой логики добавь точечный тест, если существующие проверки пропустят такую ошибку. Сообщай, что проверено и что осталось непроверенным.
- Не придумывай опыт автора, результаты исследований и показатели проектов.
- Объясняй простыми словами, что запускает действие, по какому правилу код выбирает результат и что происходит дальше. Укажи условия и исключения, если они меняют результат. Сверяй детали с кодом, а предположения и ещё не принятые решения обозначай явно.

# Работа в репозитории

- Стек: React, Vite, TypeScript. Сайт публикуется на GitHub Pages.
- Перед изменением прочитай ближайшие вложенные `AGENTS.md`: они уточняют правила своей области.
- Держи изменения в рамках задачи. Сохраняй чужие правки и существующие публичные адреса.
- Зависимости добавляй для конкретной задачи; используй npm и обновляй lock-файл вместе с package.json.
- Не коммить секреты, node_modules, dist и локальные настройки.
- Проверяй изменения командами из README. Сообщай, какие проверки выполнены и что осталось непроверенным.
- Не придумывай опыт автора, результаты исследований и показатели проектов.

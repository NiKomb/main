# Интерфейс

- Используй семантическую разметку, видимый фокус, клавиатурное и сенсорное управление. Наведение не может быть единственным способом действия.
- Общие цвета, интервалы и типографика — в `styles/tokens.css`. Внешнее расположение задает родитель, внутреннее оформление — компонент.
- Новые пиксельные иконки рисуй на сетке маскота. Один пиксель иконки при показе занимает **2 × 2 CSS px**. В CSS используй `--pixel-step` из `styles/tokens.css` для ширины, высоты и шага клеток.
- Для абзацев используй `text-align: start` и `text-wrap: pretty`. Для коротких заголовков со строками примерно одинаковой длины подходит `text-wrap: balance`.
- Внешние материалы открываются обычными ссылками; не перехватывай их SPA-маршрутизатором. Открытие новой вкладки должно быть осознанным решением интерфейса.
- При изменении маршрутизации, хранилища или UI-библиотеки сверяйся с [архитектурными решениями](../README.md#архитектурные-решения).
- Изображения импортируй из исходников; public-файлы адресуй с учетом `import.meta.env.BASE_URL`.
- Перед правкой скриншотов кейсов прочитай [руководство по скриншотам](../docs/case-screenshots.md). Для поведения галереи используй [описание переходов](sections/README.md#переходы-и-галерея).
- Проверь изменённый интерфейс на мобильном и широком экране и посмотри консоль браузера. Для затронутых элементов управления проверь клавиатуру и видимый фокус. Для анимации проверь reduced motion. Если браузерная проверка недоступна, сообщи об этом.

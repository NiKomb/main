# Журнал портфолио

- Следуй [плану отдельного журнала портфолио](../../README.md#архитектурные-решения). Устанавливай нужные компоненты после появления задачи, соблюдай их зависимости и общие токены оформления.
- Источник данных выбирается после изучения существующей телеметрии. Отделяй запросы, адаптацию данных и отображение.
- Различай живые события, сохраненный snapshot и демонстрационные fixtures. Не показывай демонстрационные данные как реальные.
- До публикации определи аудиторию журнала и авторизацию API для непубличных данных. noindex не ограничивает доступ к данным.
- Не помещай сырые данные участников в public, исходники, клиентский bundle или статический артефакт без явного решения о публикации этих данных.

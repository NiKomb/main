# Эффекты и анимации

- Один эффект — своя папка с компонентом, логикой и ресурсами. Глобальный движок заранее не нужен.
- CSS — для простого движения; Motion — для переходов React/UI; GSAP — для последовательностей и SVG-морфинга; WebGL — для конкретной графической задачи. Подключай только требуемые зависимости.
- Два механизма не должны одновременно менять одно свойство одного элемента. Селекторы ограничивай контейнером эффекта.
- React effect обязан очищать таймеры, observers, обработчики, анимации и GPU-ресурсы. StrictMode и повторное монтирование не должны создавать дубли.
- Учитывай reduced motion, сенсорное управление и статичное состояние при недоступности графики. Содержание доступно до загрузки эффекта.
- Тяжелый код загружай по необходимости; останавливай рендер вне экрана/в скрытой вкладке, ограничивай разрешение canvas.
- Проверяй resize, повторный запуск и быстрые действия. Для дорогого эффекта сначала проверь прототип на реальном телефоне.
